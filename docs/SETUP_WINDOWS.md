# セットアップと使い方（Windows）

文字かマイクで話しかけると、キャラが返事をします（声で返事もできます）。「○○調べて」と頼むと Web で調べて答え、
「画面を見せる」で今の画面を 1 枚見せることもできます。会話は PC の外に出しません。

```
キーボード・貼った画像・画面のスクショ ─┐
マイク ─▶ 話し終わりの判定 ─▶ 音声認識 ─┴─▶ アプリ ─▶ 頭脳の中継 (11434) ─┬▶ Ollama (11436, GPU)
                                            │                         └▶ Web 検索（検索語とページの取得だけ外へ）
                                            └─▶ 声の中継 (10102) ─▶ AivisSpeech (10101) ─▶ ヘッドホン
```

部品どうしはすべて `127.0.0.1`（自分の PC の中）で通信します。ネットを使うのは **初回のダウンロード** と **Web 検索** だけです。

> **PowerShell で実行するときは先頭に `.\` を付けます**（例: `.\maid.bat doctor`）。エクスプローラーからダブルクリックするなら不要です。

## 1. 方針: PC を汚さない

- インストーラー・winget・PATH の変更は使いません。必要なものは全部 `maid\runtime\` に入ります（Python も）。
- やめたくなったら maid フォルダを消せば終わりです（例外は「9. 片付け方」）。
- PC に元から必要なもの: Windows 10 (1803) 以降、NVIDIA ドライバー、Visual C++ ランタイム（Discord やゲームと一緒に入っています）、
  WebView2（Windows 11 には標準で入っています）、空き容量 15GB 程度。

## 2. 必要なものをダウンロードする

`setup.bat` をダブルクリック。次のものを `runtime\` に入れます。何度実行しても大丈夫です（そろっているものは飛ばします）。

| もの | 用途 | 大きさの目安 |
|---|---|---|
| uv | Python とライブラリの管理 | 数十 MB |
| Ollama（zip 版） | 頭脳を動かす | 約 2GB |
| AivisSpeech Engine（エンジンだけ） | 声 | 約 1〜2GB |
| maid のライブラリ（`runtime\maid-venv`） | 画面・検索・PDF・画像・声を聞く | 数百 MB |
| 音声認識のモデル（ReazonSpeech・Silero VAD。`runtime\models\`） | 声を文字にする | 約 700MB |
| 頭脳のモデル（maid.settings.json の model）と、記憶を探すモデル（bge-m3） | — | 約 5GB ＋ 1.2GB |

> **前に Open-LLM-VTuber 版を使っていた場合**: 最初に起動したとき、キャラの設定（`runtime\Open-LLM-VTuber\conf.yaml` の
> 名前・persona_prompt）を `character.yaml` に、音声認識のモデルを `runtime\models\` に引っ越します。
> そのあと `.\maid.bat clean` で、もう使わない `runtime\Open-LLM-VTuber`（数 GB）を消せます。

## 3. いつも使う設定（maid.settings.json）

初めて `maid.bat` を動かすと、maid フォルダに `maid.settings.json` ができます（`config\maid.settings.default.json` のコピー）。メモ帳で書き換えられます。書いていない項目は既定値が使われます。

```json
{
  "model": "hf.co/unsloth/gemma-4-E4B-it-GGUF:Q4_K_M",
  "voice": "コハク/あまあま",
  "speed": 1.0,
  "mic": true,
  "voice_reply": false,
  "silence_ms": 900,
  "search": "auto",
  "search_filler": "ちょっと調べるね。",
  "memory": true,
  "proactive_minutes": 15,
  "embed_model": "bge-m3"
}
```

| 項目 | 意味 |
|---|---|
| model | 頭脳のモデル（Ollama の名前）。変えたら `setup.bat` で取得する |
| voice | 声（「話者名/スタイル名」）。一覧は、声で返事する設定で起動中に <http://127.0.0.1:10102/v1/voices> |
| speed | 話す速さ（1.0 が標準） |
| mic | マイクで聞くか。`false` ならキーボードだけ（会話の画面の「マイク」でもその場で切り替えられる） |
| voice_reply | 声でも返事する（AivisSpeech も起動するので、メモリを 1GB ほど多く使う） |
| silence_ms | 話し終わりの判定。無音がこの時間（ミリ秒）続いたら送る。短いほど返事が速いが、言いかけで切られやすい |
| search | Web 検索。`auto`（「調べて」と頼まれたとき＋「今日の」「天気」「ニュース」など最新の情報が要りそうなとき）/ `explicit`（頼まれたときだけ）/ `off` |
| search_filler | 調べる前にすぐ言う一言。`""` にすると言わない |
| memory | 会話から覚える（`data\`）。`false` なら覚えず、覚えたことも使わない |
| proactive_minutes | 会話がこれだけ（分）無かったら、キャラから話しかける。`0` で話しかけない |
| embed_model | 前の会話を意味の近さで探すモデル。`""` にすると言葉の重なりだけで探す（メモリを 1GB ほど節約） |

voice_reply・mic・search・memory・proactive_minutes は起動の画面でも変えられます（変えた項目だけ書き込みます）。
変えたら `.\maid.bat stop` → `start.bat` で反映されます。

## 4. キャラの設定（character.yaml）

初めて起動すると、maid フォルダに `character.yaml` ができます（`config\character.default.yaml` のコピー）。メモ帳で書き換えます。

```yaml
name: "メイド"        # キャラの名前（画面に出る）
human: "ご主人様"     # あなたの名前（画面に出る）
persona: |
  あなたは「メイド」という名前の、……
```

- `persona` の行は、先頭に空白 2 つを付けたまま書きます。
- 今の日時と Web 検索の結果は頭脳の中継が毎回渡すので、persona に書く必要はありません。
  「インターネットを見られない」のような決まりが書いてあると、調べた結果があっても「調べられない」と答えるので消してください。
- 変えたら、アプリを閉じて起動し直すと反映されます。

## 5. 起動と終了

`start.bat` をダブルクリックすると、起動の画面が開きます。

- **使うもの**: 声で返事・マイク・Web 検索・覚える・キャラから話しかける（分）。えらんだ内容は次回も残ります。
- **アイコン**: キャラと自分のアイコンに好きな画像（PNG / JPEG / WebP / GIF、8MB まで）をえらべます。`data\icons\` に保存されます。

「起動」を押すと、頭脳（と、声で返事するなら声）を起動してから会話のウィンドウが開きます。
起動の画面を出さずにすぐ起動するときは `.\maid.bat run`。

**終了**: 会話のウィンドウを閉じるか、start.bat のウィンドウで Ctrl+C。記憶をまとめてから全部止まります。何か残ったときは `.\maid.bat stop`。

| 名前（ログ名） | 中身 |
|---|---|
| app | アプリ（会話のウィンドウ・声を聞く。聞こえた文もここに出る） |
| ollama | 頭脳（Ollama） |
| brain-proxy | 頭脳の中継。考えるモードを切る・モデルのすり替え・日時と検索結果と記憶を渡す |
| aivisspeech | 声（AivisSpeech Engine。声で返事するときだけ） |
| tts-bridge | 声の中継（〃） |

裏の部品はウィンドウを出さず、ログを `runtime\logs\` に書きます。見るときは `.\maid.bat logs <名前>`（別ウィンドウで流れ続けます）。

## 6. 会話のウィンドウ

- **文字で話す**: Enter で送る（Shift+Enter で改行）。返事の途中で「止める」を押すと、返事と読み上げを止めます。
- **声で話す**（「マイク」がオンのとき）: 話し終わって `silence_ms` だけ黙ると送られます。キャラが返事している途中でも、話しかければそこで打ち切ります。
  - 音声認識（ReazonSpeech）は CPU で動きます。起動して数秒は「音声認識を準備中…」と出ます。
  - Discord で通話中は聞きません（「Discord 通話中は聞きません」と出ます）。
  - マイクの音には、ブラウザ（Edge）と同じ雑音の除去・エコーの除去・音量の自動調整をかけてから文字にします。
  - 初めてマイクを使うとき、「マイクの使用を許可しますか」と聞かれたら「許可」してください（`runtime\webview` に覚えます）。
  - 「マイク」を押すとマイクを閉じます（Windows のマイク使用中の表示も消えます）。
  - エコーの除去はかかりますが、声で返事するときはヘッドホンのほうが確実です。
- **声で返事**: 「声」で切り替え。返事を文ごとに読み上げ、その文を声が鳴りはじめたときに出します（声と文字がそろう）。出典などは読みません。
- **画面を見せる**: 押すと、このウィンドウを一瞬隠してメインの画面（モニター）を 1 枚撮り、次に送るメッセージに付けます。
  - 撮った画像は送る前に入力欄の上に出ます（× で外せます）。何も書かずに送ってもかまいません。
  - 声で「画面見て」「これわかる？」「この文読んで」のように言ったときも、自動で画面を撮って一緒に見せます。
  - 画像はチャットに貼り付ける・ウィンドウにドラッグすることでも見せられます（写真・問題文の画像など）。
  - 見せた画像は保存しません（会話の記録には「画像を何枚見せたか」だけ残ります）。
- **会話を消す**: 画面の会話だけを消します。覚えたことは消えません。会話は `data\chat.json` に残り、次に開くと続きから見えます。

## 7. Web 検索

- 「明日の天気調べて」のように頼むと、「ちょっと調べるね。」と言ってから DuckDuckGo で調べ、上位 3 ページを読んで答えます。
  返事の下に出典のリンクが小さく出ます（読み上げはしません）。
- 「○○は誰？」→「わかんない」→「調べて」のように、「調べて」だけでも直前の話題を調べます。
- 続けて「それって雨降る？」と聞くと、前回の結果を使って答えます（10 分以内、2 回まで）。
- 今の時刻・日付・曜日は調べずに答えます（頭脳の中継が毎回、PC の時計の日時を渡しています）。
- チャットに URL を貼ると、検索せずにそのページを直接読みます（2 つまで）。PDF も文字を読み取れます。
- 外に出るのは**検索語**（頭脳が発言から作る短い言葉。名前などの個人的な情報は入れないよう指示しています）と**ページの取得**だけです。会話は送りません。
- 何を検索したかは `.\maid.bat logs brain-proxy` に出ます。

## 8. 記憶とキャラから話しかける

会話は全部 maid フォルダの `data\` に保存し、そこから覚えたことを使って話します（外には出しません）。

- 30 分話さなかったら、それまでの会話を黙ってまとめます。maid を止めるとき（ウィンドウを閉じる・Ctrl+C・`.\maid.bat stop`）にもまとめて整理するので、
  止めるのに数十秒〜数分かかることがあります。待てないときはもう一度 Ctrl+C（まとめるのは次に起動したとき）。
- 覚えるのはあなたのことと、二人の間のことだけです（キャラの好みや性格は設定どおりで変わりません）。メモ帳で開いて直したり消したりして構いません。
  - `data\PROFILE.md` … あなたのプロフィール。性格・傾向・好み・生活を、抽象的に（「面倒くさがりなところがある」くらい）
  - `data\NOW.md` … 今のこと。具体的に、日時付きで。期限が来たら自動で消えます
    - `[状況]` ごはん・体調・今していることなど（1 日） / `[約束]` 約束・やりかけ（果たされるか 7 日） / `[近況]` しばらく続くこと（30 日）
  - PROFILE.md を maid が書き直す前の版は `data\history\` に残ります。
- 「○○って覚えておいて」「それは忘れて」と言うと、その場で反映します。
- 「熱がある」のあとに「治った」、約束を果たした、と話せば、NOW.md からも消えます。
- 前の会話は、言い方が違っても意味が近ければ見つけます（`bge-m3` を CPU で使います。10 分話さないとメモリから降ろし、次に話しかけたとき 1〜2 秒で読み込み直します）。
- 会話が 15 分無く、PC を使っているときは、キャラから話しかけます（前の話の続き・あなたのこと・励ましなど）。
  PC を 15 分以上触っていないときと、Discord 通話中は話しかけません。
- 覚えたことがおかしいときは、止めてから `.\maid.bat clean -Memory`。覚えたことだけを消して、会話の記録（`data\log\`）から覚え直させます。
- 記憶を全部消したいときは、止めてから `data\` フォルダを消します（アイコンも消えます）。

## 9. 片付け方

- **いらないファイルを消す**: 止めてから `.\maid.bat clean`。ログ・ダウンロード済みのファイルを消し、前に使っていた Open-LLM-VTuber と
  使っていない頭脳のモデルがあれば、確認してから消します。会話の画面の履歴（`data\chat.json`）も消すときは `.\maid.bat clean -History`。
- **全部やめる**: maid フォルダを消す。maid フォルダの外に作られるもの（消したければ手で）:
  - `%APPDATA%\AivisSpeech-Engine` … AivisSpeech の声モデルと辞書（約 1GB。保存先を変える設定がエンジンに無いため）
  - `%USERPROFILE%\.ollama` … Ollama の識別用の鍵ファイルなど（数 KB）

## うまくいかないとき

start.bat で起動したまま、別の PowerShell で:

```powershell
.\maid.bat doctor
```

頭脳・声・音声認識のモデルを順に確かめて、どこで止まっているかを OK / NG で表示します。

### 遅い・固まるとき

起動したまま別の PowerShell で `.\maid.bat logs brain-proxy` を開いておき、話しかけます。頭脳の中継が段階ごとの時間を出します。

```
検索語づくり 1.2 秒 →「東京 明日 天気」     ← 頭脳が検索語を作るのにかかった時間
  検索 2.3 秒（5 件）                        ← DuckDuckGo の検索（15 秒であきらめる）
  ページを読む 1.8 秒（tenki.jp 1500 文字 …）← 上位ページの取得（1 ページ 5 秒まで）
返事: 準備 5.4 秒 / 最初の言葉まで 6.0 秒 / 全部で 8.2 秒（52 文字）
```

| ログの様子 | 原因と対処 |
|---|---|
| 「検索語づくり」が出ないまま止まる | 頭脳が詰まっている。下の「記憶をまとめています」が出ていないか、`ollama.exe ps` でモデルが GPU に載っているかを見る |
| 「記憶をまとめています」のあとに話しかけた | 記憶のまとめ（頭脳を使う）が終わるまで返事が後回しになる。1〜2 分待つ。返事の行に「（記憶のまとめ中のため遅いかも）」と出る |
| 「検索」が長い・あきらめた | 検索サイトの混雑や制限。少し時間をおく |
| 「最初の言葉まで」が長いのに検索していない | 頭脳のモデルが GPU から外れて読み込み直しになっている可能性。`ollama.exe ps` で「100% GPU」になっているかを見る |
| brain-proxy に何も出ない | アプリから届いていない。`.\maid.bat logs app` と `.\maid.bat doctor` を見る |

ログをコピーして貼りたいときは、メモ帳で開きます: `notepad runtime\logs\brain-proxy.log`（ログの窓は流れ続けるのでコピーしにくい）。

`ollama.exe ps` は、PowerShell で `$env:OLLAMA_HOST="127.0.0.1:11436"; .\runtime\ollama\ollama.exe ps` と打ちます（maid の Ollama は 11436 番で動いているため）。

| 症状 | 確認すること |
|---|---|
| `voice '...' が見つかりません` | <http://127.0.0.1:10102/v1/voices> の名前と完全一致しているか（「話者名/スタイル名」） |
| 返事が遅い | 初回はモデル読み込みで遅い（2 回目以降で判断）。doctor の「頭脳の返事」の秒数を見る |
| 声に反応しない | 会話の画面の「マイク」がオンか。`.\maid.bat logs app` に「聞こえた: …」が出ているか。「マイクを使えません」と出るなら、`.\maid.bat logs app` に理由が出ている。Windows の「設定 → プライバシー → マイク」でデスクトップアプリのマイクを許可する。マイクの許可を「ブロック」してしまったときは、止めてから `runtime\webview` を消す |
| 動画の音などを聞き取ってしまう | PC の音そのものを録音するデバイス（「ステレオ ミキサー」など）が録音に使われている。Windows の「設定 → システム → サウンド → 入力」で使うマイクを選び、ステレオ ミキサーは「無効」にする。マイクをつないでいないときは「マイク」をオフに |
| 画面や画像が見えていないような返事をする | `.\maid.bat logs brain-proxy` の返事の行に「（画像 1 枚つき）」が出ているか。出ていれば画像は届いていて、頭脳のモデルが画像を読めない・苦手な可能性（下の「画像を読めるか」） |
| 調べてくれない | `.\maid.bat logs brain-proxy` に「検索「…」」が出ているか。出ていなければ「調べて」と言ってみる |

### 画像を読めるか

頭脳のモデルが画像に対応しているかは、次で確かめられます。表示の「Capabilities」に `vision` があれば対応しています。

maid を起動したまま、別の PowerShell で打ちます（maid が止まっていると「could not locate ollama app」になります）。

```powershell
$env:OLLAMA_HOST="127.0.0.1:11436"; .\runtime\ollama\ollama.exe show hf.co/unsloth/gemma-4-E4B-it-GGUF:Q4_K_M
```
