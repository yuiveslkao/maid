# セットアップと使い方（Windows）

マイクで話しかけると、キャラが AivisSpeech の声で返事をします。「○○調べて」と頼むと Web で調べて答えます。
会話は PC の外に出しません。

```
マイク ──▶ 画面（Edge） ──▶ Discord ゲート (12394) ──▶ Open-LLM-VTuber (12393) ── 音声認識（ReazonSpeech, CPU）
                                                             │
                                                             ├─▶ 頭脳の中継 (11434) ─┬▶ Ollama (11436, GPU)
                                                             │                      └▶ Web 検索（検索語とページの取得だけ外へ）
                                                             └─▶ 声の中継 (10102) ─▶ AivisSpeech (10101) ─▶ ヘッドホン
```

部品どうしはすべて `127.0.0.1`（自分の PC の中）で通信します。ネットを使うのは **初回のダウンロード** と **Web 検索** だけです。

> **PowerShell で実行するときは先頭に `.\` を付けます**（例: `.\maid.bat doctor`）。エクスプローラーからダブルクリックするなら不要です。

## 1. 方針: PC を汚さない

- インストーラー・winget・PATH の変更は使いません。必要なものは全部 `maid\runtime\` に入ります（Python も）。
- やめたくなったら maid フォルダを消せば終わりです（例外は「9. 片付け方」）。
- PC に元から必要なもの: Windows 10 (1803) 以降、NVIDIA ドライバー、Visual C++ ランタイム（Discord やゲームと一緒に入っています）、空き容量 20GB 程度。

## 2. 必要なものをダウンロードする

`setup.bat` をダブルクリック。次のものを `runtime\` に入れます。何度実行しても大丈夫です（そろっているものは飛ばします）。

| もの | 用途 | 大きさの目安 |
|---|---|---|
| uv | Python とライブラリの管理 | 数十 MB |
| Ollama（zip 版） | 頭脳を動かす | 約 2GB |
| AivisSpeech Engine（エンジンだけ） | 声 | 約 1〜2GB |
| Open-LLM-VTuber v1.2.1 ＋ 画面 | 基盤 | 数 GB（ライブラリ込み） |
| 頭脳のモデル（maid.settings.json の model） | — | 約 5GB |

## 3. いつも使う設定（maid.settings.json）

初めて `maid.bat` を動かすと、maid フォルダに `maid.settings.json` ができます（`config\maid.settings.default.json` のコピー）。メモ帳で書き換えられます。書いていない項目は既定値が使われます。

```json
{
  "model": "hf.co/unsloth/gemma-4-E4B-it-GGUF:Q4_K_M",
  "voice": "コハク/あまあま",
  "speed": 1.0,
  "silence_ms": 900,
  "search": "auto",
  "search_filler": "ちょっと調べるね。"
}
```

| 項目 | 意味 |
|---|---|
| model | 頭脳のモデル（Ollama の名前）。変えたら `setup.bat` で取得する |
| voice | 声（「話者名/スタイル名」）。一覧は起動中に <http://127.0.0.1:10102/v1/voices> |
| speed | 話す速さ（1.0 が標準） |
| silence_ms | 話し終わりの判定。無音がこの時間（ミリ秒）続いたら AI に送る。短いほど返事が速いが、言いかけで切られやすい |
| search | Web 検索。`auto`（「調べて」と頼まれたとき＋「今日の」「天気」「ニュース」など最新の情報が要りそうなとき）/ `explicit`（頼まれたときだけ）/ `off` |
| search_filler | 調べる前にすぐ言う一言。`""` にすると言わない |

変えたら `.\maid.bat stop` → `start.bat` で反映されます。

## 4. キャラの設定

`runtime\Open-LLM-VTuber\conf.yaml` の `character_name` / `human_name` / `persona_prompt` を書き換えます。

- それ以外（頭脳・声・音声認識など）は maid が決めるので、触らなくて大丈夫です。
- maid は起動のたびに conf.yaml を確認し、使わない設定（ほかの AI サービスや音声合成の設定など）が入っていたら消します。
  キャラの設定はそのまま残り、消す前のファイルは `conf.yaml.before-maid` に残ります（確認したら消して構いません）。
- 今の日時と Web 検索の結果は頭脳の中継が毎回渡すので、persona_prompt に書く必要はありません。
  「インターネットを見られない」のような決まりが書いてあると、調べた結果があっても「調べられない」と答えるので消してください。

## 5. 起動と終了

`start.bat` をダブルクリック。部品を順に起動して、Edge のアプリ風ウィンドウで画面を開きます。初回はマイクの使用許可を「許可」してください。

| 名前（ログ名） | 中身 |
|---|---|
| ollama | 頭脳（Ollama） |
| brain-proxy | 頭脳の中継。考えるモードを切る・モデルのすり替え・日時と検索結果を渡す |
| aivisspeech | 声（AivisSpeech Engine） |
| tts-bridge | 声の中継 |
| discord-gate | Discord 通話中は声に反応しないようにする中継 |
| open-llm-vtuber | 本体 |

- 裏の部品はウィンドウを出さず、ログを `runtime\logs\` に書きます。見るときは `.\maid.bat logs <名前>`（別ウィンドウで流れ続けます）。
- **終了**: start.bat のウィンドウを閉じるか Ctrl+C。何か残ったときは `.\maid.bat stop`。Edge の画面を閉じても裏の部品は動き続けます。
- 初回の起動は、AivisSpeech の初期モデルと音声認識モデル（約 700MB）のダウンロードで時間がかかります。

## 6. 画面

画面の設定は maid が起動のたびに入れるので、何もしなくて大丈夫です。

- マイク: 常に ON（話し終わっても、キャラが話していても止めない。話しかければ割り込める）。ミュートはマイクの物理ボタンで。
- 話し終わりの判定: `maid.settings.json` の `silence_ms` から計算。
- 物音で反応しすぎるときは、画面の設定の「Speech Prob Threshold」を 50 → 60〜70 に上げる（この値は画面で変えたものが残ります）。

> Open-LLM-VTuber v1.2.1 の画面には、設定画面を開いて閉じるとマイク設定が「止める」に戻る不具合があるため、maid が画面のファイルも直しています。

## 7. Web 検索

- 「明日の天気調べて」のように頼むと、「ちょっと調べるね。」と言ってから DuckDuckGo で調べ、上位 3 ページを読んで答えます。チャットには出典の URL が付きます（読み上げはしません）。
- 続けて「それって雨降る？」と聞くと、前回の結果を使って答えます（10 分以内、2 回まで）。
- 外に出るのは**検索語**（頭脳が発言から作る短い言葉。名前などの個人的な情報は入れないよう指示しています）と**ページの取得**だけです。会話は送りません。
- 何を検索したかは `.\maid.bat logs brain-proxy` に出ます。

## 8. Discord 通話中

Discord でボイスチャンネルに入ると、画面に「Discord 通話中なので、声には反応しません」と出て、声に反応しなくなります（チャット入力は使えます）。抜けると「また聞いています」と出て元に戻ります。

- 判定には Windows のアプリごとのマイク使用記録（タスクバーのマイクアイコンと同じ情報）を使います。
- Discord の設定画面でマイクテストをしている間も「通話中」と判定されます。

## 9. 片付け方

- **いらないファイルを消す**: 止めてから `.\maid.bat clean`。ログ・一時ファイル・ダウンロード済みのファイル・前に使っていた音声認識モデルを消し、
  使っていない頭脳のモデルがあれば確認してから消します。会話の履歴（`runtime\Open-LLM-VTuber\chat_history\`）も消すときは `.\maid.bat clean -History`。
- **全部やめる**: maid フォルダを消す。maid フォルダの外に作られるもの（消したければ手で）:
  - `%APPDATA%\AivisSpeech-Engine` … AivisSpeech の声モデルと辞書（約 1GB。保存先を変える設定がエンジンに無いため）
  - `%USERPROFILE%\.ollama` … Ollama の識別用の鍵ファイルなど（数 KB）
  - Edge に残る「127.0.0.1 のマイク許可」と画面の設定

## うまくいかないとき

start.bat で起動したまま、別の PowerShell で:

```powershell
.\maid.bat doctor
```

頭脳・声・本体を順に実際に動かして、どこで止まっているかを OK / NG で表示します。
詳しく調べるときは、表示の最後に出る本体のログ（`runtime\Open-LLM-VTuber\logs\debug_日付.log`）を見ます。

| 症状 | 確認すること |
|---|---|
| `voice '...' が見つかりません` | <http://127.0.0.1:10102/v1/voices> の名前と完全一致しているか（「話者名/スタイル名」） |
| 返事が遅い | 初回はモデル読み込みで遅い（2 回目以降で判断）。doctor の「頭脳の返事」の秒数を見る |
| 物音で反応する | 画面の「Speech Prob Threshold」を上げる |
| 画面が「接続できません」 | `.\maid.bat logs discord-gate` を見る。start.bat を起動し直すと、ゲートが動かないときは本体に直結します |
| 調べてくれない | `.\maid.bat logs brain-proxy` に「検索「…」」が出ているか。出ていなければ「調べて」と言ってみる |
