# セットアップと使い方（Windows）

文字かマイクで話しかけると、キャラが返事をします（声で返事もできます）。「○○調べて」と頼むと Web で調べて答え、
「画面を見せる」で今の画面を 1 枚見せることもできます。会話は PC の外に出しません。

部品どうしはすべて `127.0.0.1`（自分の PC の中）で通信します。ネットを使うのは **初回のダウンロード** と **Web 検索** だけです。

## 1. 方針: PC を汚さない

- インストーラー・winget・PATH の変更は使いません。必要なものは全部 maid フォルダの `runtime\` に入ります。
- やめたくなったら maid フォルダを消せば終わりです（例外は「9. 片付け方」）。
- PC に元から必要なもの: Windows 10 / 11（64 ビット）、NVIDIA のドライバー、WebView2（Windows 11 には標準で入っています）、空き容量 15GB 程度。

## 2. maid.exe を手に入れる

1. GitHub の **Actions** → 一番新しい「build」→ 下の **Artifacts** の `maid-win-x64` をダウンロードして展開します。
2. 中の `maid.exe` と `lib` フォルダを、maid フォルダ（このリポジトリのフォルダ）に置きます。

```
maid\
├ maid.exe            ← ダブルクリックで起動
├ lib\                ← maid.exe が使う部品（消さない）
├ maid.settings.json  ← いつもの設定（初回に作る）
├ character.yaml      ← キャラの設定（初回に作る）
├ data\               ← 記憶・会話・アイコン
└ runtime\            ← ダウンロードしたもの
```

## 3. 初回のセットアップ

`maid.exe` をダブルクリックすると、足りないものがあればセットアップの画面が開きます。「始める」で `runtime\` にダウンロードします。
途中で止めても、次は続きから再開します。

| もの | 用途 | 大きさの目安 |
|---|---|---|
| llama.cpp（CUDA 12 版） | 頭脳を動かす | 約 700MB |
| 頭脳のモデル（Gemma 4 E4B, GGUF） | 頭脳 | 約 5GB |
| 記憶を探すモデル（bge-m3, GGUF） | 前の会話を意味の近さで探す | 約 0.6〜1.2GB |
| 音声認識のモデル（ReazonSpeech・Silero VAD） | 声を文字にする（マイクを使うとき） | 約 700MB |
| AivisSpeech Engine | 声（声で返事するとき） | 約 1〜2GB |

> **前の版（Python・Ollama）を使っていた場合**: Ollama が持っているモデル（`runtime\ollama-models`）は、ダウンロードせずに引き継ぎます。
> 音声認識のモデルや記憶（`data\`）、`maid.settings.json`、`character.yaml` もそのまま使います。
> 済んだら、セットアップの画面の「前の版のファイル」の「消す」で、もう使わないもの（Python・Ollama など。数 GB）を消せます。

## 4. いつも使う設定（maid.settings.json）

初めて起動すると、maid フォルダに `maid.settings.json` ができます。メモ帳で書き換えられます。書いていない項目は既定値が使われます。

```json
{
  "model_repo": "unsloth/gemma-4-E4B-it-GGUF",
  "model_file": "gemma-4-E4B-it-Q4_K_M.gguf",
  "mmproj_file": "mmproj-F16.gguf",
  "context": 8192,
  "voice": "コハク/あまあま",
  "speed": 1.0,
  "mic": true,
  "voice_reply": false,
  "silence_ms": 900,
  "search": "auto",
  "search_filler": "ちょっと調べるね。",
  "memory": true,
  "proactive_minutes": 15,
  "embed": true,
  "embed_repo": "gpustack/bge-m3-GGUF",
  "embed_file": "bge-m3-Q8_0.gguf"
}
```

| 項目 | 意味 |
|---|---|
| model_repo / model_file / mmproj_file | 頭脳のモデル（Hugging Face の場所と、`runtime\models\` に置くファイル名。mmproj は画像を読む部分）。変えたら次の起動でダウンロードする |
| context | 頭脳が一度に読める長さ（トークン） |
| voice | 声（「話者名/スタイル名」） |
| speed | 話す速さ（1.0 が標準） |
| mic | マイクで聞くか。`false` ならキーボードだけ（会話の画面の「マイク」でもその場で切り替えられる） |
| voice_reply | 声でも返事する（AivisSpeech も起動するので、メモリを 1GB ほど多く使う） |
| silence_ms | 話し終わりの判定。無音がこの時間（ミリ秒）続いたら送る。短いほど返事が速いが、言いかけで切られやすい |
| search | Web 検索。`auto`（「調べて」と頼まれたとき＋「今日の」「天気」「ニュース」など最新の情報が要りそうなとき）/ `explicit`（頼まれたときだけ）/ `off` |
| search_filler | 調べる前にすぐ言う一言。`""` にすると言わない |
| memory | 会話から覚える（`data\`）。`false` なら覚えず、覚えたことも使わない |
| proactive_minutes | 会話がこれだけ（分）無かったら、キャラから話しかける。`0` で話しかけない |
| embed / embed_repo / embed_file | 前の会話を意味の近さで探すモデル。`embed` を `false` にすると言葉の重なりだけで探す |

voice_reply・mic・search・memory・proactive_minutes は起動の画面でも変えられます（変えた項目だけ書き込みます）。

## 5. キャラの設定（character.yaml）

初めて起動すると、maid フォルダに `character.yaml` ができます。メモ帳で書き換えます。

```yaml
name: "メイド"        # キャラの名前（画面に出る）
human: "ご主人様"     # あなたの名前（画面に出る）
persona: |
  あなたは「メイド」という名前の、……
```

- `persona` の行は、先頭に空白 2 つを付けたまま書きます。
- 今の日時と Web 検索の結果は毎回頭脳に渡すので、persona に書く必要はありません。
  「インターネットを見られない」のような決まりが書いてあると、調べた結果があっても「調べられない」と答えるので消してください。
- 変えたら、閉じて起動し直すと反映されます。

## 6. 起動と終了

`maid.exe` をダブルクリックすると、起動の画面が開きます。

- **使うもの**: 声で返事・マイク・Web 検索・覚える・キャラから話しかける（分）。えらんだ内容は次回も残ります。
- **アイコン**: キャラと自分のアイコンに好きな画像（PNG / JPEG / WebP / GIF、8MB まで）をえらべます。`data\icons\` に保存されます。

「起動」を押すと会話のウィンドウになり、裏で頭脳（と、声で返事するなら声）を起動します。準備ができるまでは上に「頭脳を準備しています…」と出ます。

**終了**: ウィンドウを閉じると、記憶をまとめてから全部止まります（数十秒〜数分。もう一度閉じると、まとめずにすぐ終わります。まとめるのは次に起動したとき）。
maid.exe が終わると、裏の部品も必ず一緒に止まります。

| ログ（`runtime\logs\`） | 中身 |
|---|---|
| maid.log | maid 本体（聞こえた文・検索・返事にかかった時間・記憶のまとめ・エラー） |
| brain.log | 頭脳（llama-server） |
| embed.log | 記憶を探す頭脳（llama-server） |
| aivisspeech.log | 声（AivisSpeech Engine） |

## 7. 会話のウィンドウ

- **文字で話す**: Enter で送る（Shift+Enter で改行）。返事の途中で「止める」を押すと、返事と読み上げを止めます。
- **声で話す**（「マイク」がオンのとき）: 話し終わって `silence_ms` だけ黙ると送られます。キャラが返事している途中でも、話しかければそこで打ち切ります。
  - マイクの音には、ブラウザ（Edge）と同じ雑音の除去・エコーの除去・音量の自動調整をかけてから文字にします。音声認識（ReazonSpeech）は CPU で動きます。
  - Discord で通話中は聞きません（「Discord 通話中は聞きません」と出ます）。キャラから話しかけることもしません。
  - 「マイク」を押すとマイクを閉じます（Windows のマイク使用中の表示も消えます）。
  - エコーの除去はかかりますが、声で返事するときはヘッドホンのほうが確実です。
- **声で返事**: 「声」で切り替え。返事を文ごとに読み上げ、その文を声が鳴りはじめたときに出します（声と文字がそろう）。出典などは読みません。
- **画面を見せる**: 押すと、このウィンドウを一瞬隠してメインの画面（モニター）を 1 枚撮り、次に送るメッセージに付けます。
  - 声で「画面見て」「これわかる？」「この文読んで」のように言ったときも、自動で画面を撮って一緒に見せます。
  - 画像はチャットに貼り付ける・ウィンドウにドラッグすることでも見せられます（写真・問題文の画像など）。
  - 見せた画像は保存しません（会話の記録には「画像を何枚見せたか」だけ残ります）。
- **会話を消す**: 画面の会話だけを消します。覚えたことは消えません。会話は `data\chat.json` に残り、次に開くと続きから見えます。

## 8. Web 検索と記憶

**Web 検索**
- 「明日の天気調べて」のように頼むと、「ちょっと調べるね。」と言ってから DuckDuckGo（だめなときは Mojeek）で調べ、上位 3 ページを読んで答えます。返事の下に出典のリンクが出ます。
- 「調べて」だけでも直前の話題を調べます。続けて聞くと、前回の結果を使って答えます（10 分以内、2 回まで）。
- 今の時刻・日付・曜日は調べずに答えます。チャットに URL を貼ると、そのページを直接読みます（PDF も）。
- 外に出るのは**検索語**（名前などの個人的な情報は入れないよう指示しています）と**ページの取得**だけです。

**記憶**（全部 `data\` に保存し、外には出しません）
- 30 分話さなかったら、それまでの会話を黙ってまとめます。閉じるときにもまとめます。
- 覚えるのはあなたのことと、二人の間のことだけです（キャラの性格は設定どおりで変わりません）。メモ帳で直したり消したりして構いません。
  - `data\PROFILE.md` … あなたのプロフィール（抽象的に）
  - `data\NOW.md` … 今のこと（具体的に、日時付き。`[状況]` 1 日 / `[約束]` 7 日 / `[近況]` 30 日で自動で消える）
- 「○○って覚えておいて」「それは忘れて」と言うと、その場で反映します。「熱がある」のあとに「治った」と話せば、NOW.md からも消えます。
- 会話が 15 分無く、PC を使っているときは、キャラから話しかけます（PC を 15 分以上触っていないときと、Discord 通話中は話しかけません）。
- 記憶を全部消したいときは、閉じてから `data\` フォルダを消します（アイコンも消えます）。

## 9. 片付け方

- **全部やめる**: maid フォルダを消す。maid フォルダの外に作られるもの（消したければ手で）:
  - `%APPDATA%\AivisSpeech-Engine` … AivisSpeech の声モデルと辞書（約 1GB。保存先を変える設定がエンジンに無いため）

## うまくいかないとき

まず `runtime\logs\maid.log` をメモ帳で開きます。

| 症状 | 確認すること |
|---|---|
| 「頭脳を起動できませんでした」 | `runtime\logs\brain.log` の最後。NVIDIA のドライバーが古いと CUDA 12 版が動かないことがある |
| 返事が遅い | maid.log の「返事: 準備 … / 最初の言葉まで … / 全部で …」。初回はモデル読み込みで遅い（2 回目以降で判断） |
| 声に反応しない | 会話の画面の「マイク」がオンか。maid.log に「聞こえた: …」が出ているか。「マイクを使えません」なら、Windows の「設定 → プライバシー → マイク」でデスクトップアプリのマイクを許可する |
| 動画の音などを聞き取ってしまう | 「ステレオ ミキサー」など PC の音を録音するデバイスが使われている。Windows の「設定 → システム → サウンド → 入力」で使うマイクを選ぶ |
| 声が出ない | `runtime\logs\aivisspeech.log`。maid.log に「声 '…' が AivisSpeech に見つかりません」なら voice の名前を確かめる |
| 調べてくれない | maid.log に「検索「…」」が出ているか。出ていなければ「調べて」と言ってみる |

**メモリの使い方を見る**: maid が動いている間に、PowerShell を maid フォルダで開いて次を貼ります（「専有MB」が実際に占有している量）。

```powershell
Get-Process | ? { $_.Path -like "$PWD\*" -or $_.Name -eq "msedgewebview2" } | Group-Object Name | % { [pscustomobject]@{名前=$_.Name; 使用中MB=[int](($_.Group | Measure-Object WorkingSet64 -Sum).Sum/1MB); 専有MB=[int](($_.Group | Measure-Object PrivateMemorySize64 -Sum).Sum/1MB)} } | Sort-Object 専有MB -Descending
```
