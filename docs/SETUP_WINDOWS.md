# セットアップと使い方（Windows）

マイクで話しかけると、キャラが AivisSpeech の声で返事をします。「○○調べて」と頼むと Web で調べて答えます。
会話は PC の外に出しません。

```
マイク ──▶ 画面（Edge） ──▶ Discord ゲート (12394) ──▶ Open-LLM-VTuber (12393) ── 音声認識（ReazonSpeech, CPU）
                                                             │
                                                             ├─▶ 頭脳の中継 (11434) ─┬▶ Ollama (11436, GPU)
                                                             │                      └▶ Web 検索（検索語とページの取得だけ外へ）
                                                             └─▶ 声の中継 (10102) ─▶ AivisSpeech (10101) ─▶ ヘッドホン
```

部品どうしはすべて `127.0.0.1`（自分の PC の中）で通信します。ネットを使うのは **初回のダウンロード** と **Web 検索** だけです。

> **PowerShell で実行するときは先頭に `.\` を付けます**（例: `.\maid.bat doctor`）。エクスプローラーからダブルクリックするなら不要です。

## 1. 方針: PC を汚さない

- インストーラー・winget・PATH の変更は使いません。必要なものは全部 `maid\runtime\` に入ります（Python も）。
- やめたくなったら maid フォルダを消せば終わりです（例外は「10. 片付け方」）。
- PC に元から必要なもの: Windows 10 (1803) 以降、NVIDIA ドライバー、Visual C++ ランタイム（Discord やゲームと一緒に入っています）、空き容量 20GB 程度。

## 2. 必要なものをダウンロードする

`setup.bat` をダブルクリック。次のものを `runtime\` に入れます。何度実行しても大丈夫です（そろっているものは飛ばします）。

| もの | 用途 | 大きさの目安 |
|---|---|---|
| uv | Python とライブラリの管理 | 数十 MB |
| Ollama（zip 版） | 頭脳を動かす | 約 2GB |
| AivisSpeech Engine（エンジンだけ） | 声 | 約 1〜2GB |
| Open-LLM-VTuber v1.2.1 ＋ 画面 | 基盤 | 数 GB（ライブラリ込み） |
| maid の部品用のライブラリ（`runtime\maid-venv`） | 検索・PDF・Discord ゲート | 数十 MB |
| 頭脳のモデル（maid.settings.json の model） | — | 約 5GB |

## 3. いつも使う設定（maid.settings.json）

初めて `maid.bat` を動かすと、maid フォルダに `maid.settings.json` ができます（`config\maid.settings.default.json` のコピー）。メモ帳で書き換えられます。書いていない項目は既定値が使われます。

```json
{
  "mode": "chat",
  "model": "hf.co/unsloth/gemma-4-E4B-it-GGUF:Q4_K_M",
  "voice": "コハク/あまあま",
  "speed": 1.0,
  "mic": true,
  "voice_reply": false,
  "silence_ms": 900,
  "search": "auto",
  "search_filler": "ちょっと調べるね。",
  "memory": true,
  "vrm": "",
  "vrm_view": "auto",
  "app": true,
  "character_on_top": false,
  "character_click_through": true,
  "proactive_minutes": 15,
  "embed_model": "bge-m3"
}
```

| 項目 | 意味 |
|---|---|
| mode | 起動の画面で最後にえらんだ版（`chat` / `full`） |
| model | 頭脳のモデル（Ollama の名前）。変えたら `setup.bat` で取得する |
| voice | 声（「話者名/スタイル名」）。一覧は起動中に <http://127.0.0.1:10102/v1/voices> |
| speed | 話す速さ（1.0 が標準） |
| mic | マイクを使うか。`false` にするとマイクを切ったままにする（キーボードだけで話すとき。勝手にオンに戻らない） |
| voice_reply | チャットだけの版で、声でも返事する（AivisSpeech も起動する） |
| silence_ms | 話し終わりの判定。無音がこの時間（ミリ秒）続いたら AI に送る。短いほど返事が速いが、言いかけで切られやすい |
| search | Web 検索。`auto`（「調べて」と頼まれたとき＋「今日の」「天気」「ニュース」など最新の情報が要りそうなとき）/ `explicit`（頼まれたときだけ）/ `off` |
| search_filler | 調べる前にすぐ言う一言。`""` にすると言わない |
| memory | 会話から覚える（`data\`）。`false` なら覚えず、覚えたことも使わない |
| vrm | 3D モデル（.vrm）の場所。空なら Live2D のまま（「6. 画面」を参照） |
| vrm_view | 3D モデルの映し方。`auto`（デスクトップでは全身、画面の中では胸から上）/ `bust`（胸から上）/ `full`（全身） |
| app | フル版で maid のアプリを使う（タスクトレイ・デスクトップのキャラ・チャットのウィンドウ）。`false` なら前と同じく Edge で開く（起動の画面とチャットだけの版はいつもアプリ） |
| character_on_top | デスクトップのキャラを、ほかのウィンドウより手前に出す（タスクトレイからも切り替えられる） |
| character_click_through | デスクトップのキャラの上のクリックを、後ろへすり抜けさせる。キャラが表示されない・黒い四角になるときは `false` にする |
| proactive_minutes | 会話がこれだけ（分）無かったら、キャラから話しかける。`0` で話しかけない |
| embed_model | 前の会話を意味の近さで探すモデル。`""` にすると言葉の重なりだけで探す |

mode・voice_reply・mic・search・memory・proactive_minutes・vrm は起動の画面でも変えられます（変えた項目だけ書き込みます）。
変えたら `.\maid.bat stop` → `start.bat` で反映されます。

## 4. キャラの設定

`runtime\Open-LLM-VTuber\conf.yaml` の `character_name` / `human_name` / `persona_prompt` を書き換えます。

- それ以外（頭脳・声・音声認識など）は maid が決めるので、触らなくて大丈夫です。
- maid は起動のたびに conf.yaml を確認し、使わない設定（ほかの AI サービスや音声合成の設定など）が入っていたら消します。
  キャラの設定はそのまま残り、消す前のファイルは `conf.yaml.before-maid` に残ります（確認したら消して構いません）。
- 今の日時と Web 検索の結果は頭脳の中継が毎回渡すので、persona_prompt に書く必要はありません。
  「インターネットを見られない」のような決まりが書いてあると、調べた結果があっても「調べられない」と答えるので消してください。

## 5. 起動と終了

`start.bat` をダブルクリックすると、起動の画面が開きます。

- **どれで起動する？**
  - **チャットだけ**: 文字で話すウィンドウだけ。Open-LLM-VTuber・音声認識・3D は起動しないので、起動が速く GPU も軽い。
    「声で返事する」をオンにすると AivisSpeech も起動し、返事を文ごとに読み上げます（チャットの画面の「声」でも切り替え可）。
    検索・URL や PDF を読む・記憶・キャラから話しかける、はフル版と同じです。会話は `data\chat.json` に残り、次に開くと続きから見えます。
  - **フル**: 今までどおり。声で会話・デスクトップの 3D キャラ・画面共有。
- **使うもの**: 声で返事・マイク・Web 検索・覚える・キャラから話しかける（分）。えらんだ内容は次回も残ります。
- **アイコン**: キャラと自分のアイコンに好きな画像（PNG / JPEG / WebP / GIF、8MB まで）をえらべます。`data\icons\` に保存され、チャットだけの版に出ます。
- **3D モデル**（フルのとき）: .vrm をえらぶ。

起動の画面を出さずに直接起動するときは `.\maid.bat chat`（チャットだけ）/ `.\maid.bat start`（フル）。
フル版の初回はマイクの使用許可を「許可」してください。

チャットだけの版は、チャットのウィンドウを閉じるか start.bat のウィンドウで Ctrl+C で終わります（記憶をまとめてから止まります）。
返事の途中で「止める」を押すと、返事と読み上げを止めます。「会話を消す」は画面の会話だけを消し、覚えたことは消えません。

以下はフル版の説明です。

- **デスクトップのキャラ**: 3D モデル（`vrm`）を設定していると、画面の右下（タスクバーの上）にキャラが立ちます。
  ほかのウィンドウの後ろ（デスクトップの上）にいて、クリックは後ろへすり抜けます。声もキャラのウィンドウから出ます。
- **チャットのウィンドウ**: 話しかける・文字で話す・画面共有・設定はここ（中身は今のところ Open-LLM-VTuber の画面）。閉じてもアプリは終わりません。
- **タスクトレイ**（画面右下の、ピンクの丸のアイコン）: チャットを開く / キャラを出す・隠す / いつも手前に出す / 終了。
  **終了**を選ぶと、記憶をまとめてから maid 全体が止まります。

| 名前（ログ名） | 中身 |
|---|---|
| ollama | 頭脳（Ollama） |
| brain-proxy | 頭脳の中継。考えるモードを切る・モデルのすり替え・日時と検索結果を渡す |
| aivisspeech | 声（AivisSpeech Engine） |
| tts-bridge | 声の中継 |
| discord-gate | Discord 通話中は声に反応しないようにする中継 |
| open-llm-vtuber | 本体 |
| app | maid のアプリ（起動の画面・チャットだけの版・フル版のタスクトレイ・キャラ・チャットのウィンドウ） |

- 裏の部品はウィンドウを出さず、ログを `runtime\logs\` に書きます。見るときは `.\maid.bat logs <名前>`（別ウィンドウで流れ続けます）。
- **終了**: タスクトレイの「終了」か、start.bat のウィンドウで Ctrl+C。何か残ったときは `.\maid.bat stop`。
- 部品は同時に起動し、全部そろうと画面が開きます。start.bat のウィンドウに起動にかかった秒数が出ます。
  いちばん時間がかかるのは Open-LLM-VTuber 本体の読み込みです（その間に頭脳のモデルも GPU に読み込んでおきます）。
- 初回の起動は、AivisSpeech の初期モデルと音声認識モデル（約 700MB）のダウンロードで時間がかかります。

## 6. 画面

画面の設定は maid が起動のたびに入れるので、何もしなくて大丈夫です。

- マイク: 常に ON（話し終わっても、キャラが話していても止めない。話しかければ割り込める）。ミュートはマイクの物理ボタンで。
- 話し終わりの判定: `maid.settings.json` の `silence_ms` から計算。
- 物音で反応しすぎるときは、画面の設定の「Speech Prob Threshold」を 50 → 60〜70 に上げる（この値は画面で変えたものが残ります）。

> Open-LLM-VTuber v1.2.1 の画面には、設定画面を開いて閉じるとマイク設定が「止める」に戻る不具合があるため、maid が画面のファイルも直しています。

### 3D モデル（VRM）を表示する

.vrm ファイル 1 つだけで動きます（テクスチャもファイルの中に入っています）。maid フォルダの `models\` に置いて、
`maid.settings.json` の `vrm` に書き、`.\maid.bat stop` → `start.bat`。`models\` の中は git に入りません。

```json
  "vrm": "models/lulum_1.04.vrm",
```

ほかの場所に置いたままでも、フルパスで書けば使えます（区切りは `/`。`\` を使うなら `\\` と 2 つ重ねる）。

- モデルは起動のたびに `runtime\Open-LLM-VTuber\frontend\maid-vrm\` にコピーされます（変わっていなければコピーしない）。元のファイルが無いと Live2D に戻るので、消さないでください。
- 初回だけ、表示に使うライブラリ（three.js と three-vrm、数 MB）をダウンロードします。
- 呼吸・まばたき・こちらを見る・声に合わせた口の動きをします。表情の変化はまだありません。
- Live2D は見えないようにして裏で動かしています（画面の本体が Live2D 経由で声を再生するため。消すと声が出なくなる）。
- GPU は頭脳と共用です。描画は 1 秒 30 回に抑えています。返事が遅くなったと感じたら `vrm_view` を `bust` にするか、`vrm` を空に戻してください。
- 読み込めないときは、画面の左下に理由が出ます。

## 7. Web 検索

- 「明日の天気調べて」のように頼むと、「ちょっと調べるね。」と言ってから DuckDuckGo で調べ、上位 3 ページを読んで答えます。
  チャットには「( 出典: URL … )」が付きます（読み上げはしません）。
- 「○○は誰？」→「わかんない」→「調べて」のように、「調べて」だけでも直前の話題を調べます。
- 続けて「それって雨降る？」と聞くと、前回の結果を使って答えます（10 分以内、2 回まで）。
- 今の時刻・日付・曜日は調べずに答えます（頭脳の中継が毎回、PC の時計の日時を渡しています）。
- チャットに URL を貼ると、検索せずにそのページを直接読みます（2 つまで）。
- PDF のページは文字を読み取れます。画像の中の文字（問題文の画像など）は読めません。
- 外に出るのは**検索語**（頭脳が発言から作る短い言葉。名前などの個人的な情報は入れないよう指示しています）と**ページの取得**だけです。会話は送りません。
- 何を検索したかは `.\maid.bat logs brain-proxy` に出ます。

## 8. 記憶とキャラから話しかける

会話は全部 maid フォルダの `data\` に保存し、そこから覚えたことを使って話します（外には出しません）。

- 30 分話さなかったら、それまでの会話を黙ってまとめます。maid を止めるとき（Ctrl+C / `.\maid.bat stop`）にもまとめて整理するので、
  止めるのに数十秒〜数分かかることがあります。待てないときはもう一度 Ctrl+C（まとめるのは次に起動したとき）。
  ウィンドウの × で閉じたときも、次に起動したときにまとめます。
- 覚えるのはあなたのことと、二人の間のことだけです（キャラの好みや性格は設定どおりで変わりません）。メモ帳で開いて直したり消したりして構いません。
  - `data\PROFILE.md` … あなたのプロフィール。性格・傾向・好み・生活を、抽象的に（「面倒くさがりなところがある」くらい）
  - `data\NOW.md` … 今のこと。具体的に、日時付きで。期限が来たら自動で消えます
    - `[状況]` ごはん・体調・今していることなど（1 日） / `[約束]` 約束・やりかけ（果たされるか 7 日） / `[近況]` しばらく続くこと（30 日）
  - PROFILE.md を maid が書き直す前の版は `data\history\` に残ります。
- 「○○って覚えておいて」「それは忘れて」と言うと、その場で反映します。
- 「熱がある」のあとに「治った」、約束を果たした、と話せば、NOW.md からも消えます。
- 前の会話は、言い方が違っても意味が近ければ見つけます。そのための小さいモデル（`bge-m3`、約 1.2GB）を初回の起動時に裏でダウンロードし、CPU で動かします。
- 会話が 15 分無く、PC を使っているときは、キャラから話しかけます（前の話の続き・あなたのこと・励ましなど）。
  PC を 15 分以上触っていないときと、Discord 通話中は話しかけません。
- 覚えたことがおかしいときは、止めてから `.\maid.bat clean -Memory`。覚えたことだけを消して、会話の記録（`data\log\`）から覚え直させます。
- 記憶を全部消したいときは、止めてから `data\` フォルダを消します。

## 9. Discord 通話中

Discord でボイスチャンネルに入ると、画面に「Discord 通話中なので、声には反応しません」と出て、声に反応しなくなります（チャット入力は使えます）。抜けると「また聞いています」と出て元に戻ります。

- 判定には Windows のアプリごとのマイク使用記録（タスクバーのマイクアイコンと同じ情報）を使います。
- Discord の設定画面でマイクテストをしている間も「通話中」と判定されます。

## 10. 片付け方

- **いらないファイルを消す**: 止めてから `.\maid.bat clean`。ログ・一時ファイル・ダウンロード済みのファイル・前に使っていた音声認識モデルを消し、
  使っていない頭脳のモデルがあれば確認してから消します。会話の履歴（`runtime\Open-LLM-VTuber\chat_history\`）も消すときは `.\maid.bat clean -History`。
- **全部やめる**: maid フォルダを消す。maid フォルダの外に作られるもの（消したければ手で）:
  - `%APPDATA%\AivisSpeech-Engine` … AivisSpeech の声モデルと辞書（約 1GB。保存先を変える設定がエンジンに無いため）
  - `%USERPROFILE%\.ollama` … Ollama の識別用の鍵ファイルなど（数 KB）
  - Edge に残る「127.0.0.1 のマイク許可」と画面の設定

## うまくいかないとき

start.bat で起動したまま、別の PowerShell で:

```powershell
.\maid.bat doctor
```

頭脳・声・本体を順に実際に動かして、どこで止まっているかを OK / NG で表示します。
詳しく調べるときは、表示の最後に出る本体のログ（`runtime\Open-LLM-VTuber\logs\debug_日付.log`）を見ます。

### 遅い・固まるとき

起動したまま別の PowerShell で `.\maid.bat logs brain-proxy` を開いておき、話しかけます。頭脳の中継が段階ごとの時間を出します。

```
検索語づくり 1.2 秒 →「東京 明日 天気」     ← 頭脳が検索語を作るのにかかった時間
  検索 2.3 秒（5 件）                        ← DuckDuckGo の検索（15 秒であきらめる）
  ページを読む 1.8 秒（tenki.jp 1500 文字 …）← 上位ページの取得（1 ページ 5 秒まで）
返事: 準備 5.4 秒 / 最初の言葉まで 6.0 秒 / 全部で 8.2 秒（52 文字）
```

| ログの様子 | 原因と対処 |
|---|---|
| 「検索語づくり」が出ないまま止まる | 頭脳が詰まっている。下の「記憶をまとめています」が出ていないか、`runtime\ollama\ollama.exe ps` でモデルが GPU に載っているかを見る |
| 「記憶をまとめています」のあとに話しかけた | 記憶のまとめ（頭脳を使う）が終わるまで返事が後回しになる。1〜2 分待つ。返事の行に「（記憶のまとめ中のため遅いかも）」と出る |
| 「検索」が長い・あきらめた | 検索サイトの混雑や制限。少し時間をおく |
| 「最初の言葉まで」が長いのに検索していない | 頭脳のモデルが GPU から外れて読み込み直しになっている可能性。`ollama.exe ps` で「100% GPU」になっているかを見る。`.\maid.bat logs ollama` に load の行が何度も出ていたら教えてください |
| brain-proxy に何も出ない | 頭脳の中継まで届いていない。`.\maid.bat logs open-llm-vtuber` と `.\maid.bat doctor` を見る |

ログをコピーして貼りたいときは、メモ帳で開きます: `notepad runtime\logs\brain-proxy.log`（ログの窓は流れ続けるのでコピーしにくい）。

`ollama.exe ps` は、PowerShell で `$env:OLLAMA_HOST="127.0.0.1:11436"; .\runtime\ollama\ollama.exe ps` と打ちます（maid の Ollama は 11436 番で動いているため）。

| 症状 | 確認すること |
|---|---|
| `voice '...' が見つかりません` | <http://127.0.0.1:10102/v1/voices> の名前と完全一致しているか（「話者名/スタイル名」） |
| 返事が遅い | 初回はモデル読み込みで遅い（2 回目以降で判断）。doctor の「頭脳の返事」の秒数を見る |
| 物音で反応する | 画面の「Speech Prob Threshold」を上げる |
| 動画の音などを聞き取ってしまう | PC の音そのものを録音するデバイス（「ステレオ ミキサー」など）が録音に使われている。Windows の「設定 → システム → サウンド → 入力」で使うマイクを選び、ステレオ ミキサーは「無効」にする。マイクをつないでいないときは `"mic": false` に |
| 画面共有が見えていないような返事をする | `.\maid.bat logs brain-proxy` の返事の行に「（画像 1 枚つき）」が出ているか。出ていれば画像は届いていて、頭脳のモデルが画像を読めない・苦手な可能性（下の「画像を読めるか」） |
| 画面が「接続できません」 | `.\maid.bat logs discord-gate` を見る。start.bat を起動し直すと、ゲートが動かないときは本体に直結します |
| 調べてくれない | `.\maid.bat logs brain-proxy` に「検索「…」」が出ているか。出ていなければ「調べて」と言ってみる |

### 画像を読めるか（画面共有）

頭脳のモデルが画像に対応しているかは、次で確かめられます。表示の「Capabilities」に `vision` があれば対応しています。

start.bat で起動したまま、別の PowerShell で打ちます（maid が止まっていると「could not locate ollama app」になります）。

```powershell
$env:OLLAMA_HOST="127.0.0.1:11436"; .\runtime\ollama\ollama.exe show hf.co/unsloth/gemma-4-E4B-it-GGUF:Q4_K_M
```
