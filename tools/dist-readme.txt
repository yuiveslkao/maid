maid（めい）— PC の中だけで動く、話し相手のキャラクター

■ 使い方
1. このフォルダを好きな場所に置きます（例: D:\maid）。日本語や空白を含まない場所がおすすめです。
2. maid.exe をダブルクリックします。
3. 初回はセットアップの画面が開きます。「始める」で、動かすのに必要なもの（約 8GB）を
   このフォルダの runtime\ にダウンロードします。インストールはしません。
4. 起動の画面で使うもの（声・マイク・検索・記憶）を選んで「起動」。

■ 必要なもの
- Windows 10 / 11（64 ビット）
- NVIDIA の GPU（VRAM 8GB 以上がおすすめ）と、新しめのドライバー
- メモリ 16GB 以上がおすすめ

■ フォルダの中身
maid.exe            ダブルクリックで起動
lib\                maid.exe が使う部品（消さない）
maid.settings.json  いつもの設定（初回に作る）
character.yaml      キャラの名前・性格（初回に作る。メモ帳で書き換えられる）
data\               記憶・会話・アイコン（消すと全部忘れる）
runtime\            ダウンロードしたもの（消すと次の起動でまたダウンロード）

■ 外に出るもの
Web 検索の検索語と、読みに行ったページへのアクセスだけです。会話・記憶・声・画面はこの PC の外に出ません。

■ やめるとき
このフォルダを消すだけです。AivisSpeech の声のデータだけは %APPDATA%\AivisSpeech-Engine に残るので、要らなければ消してください。

■ うまくいかないとき
runtime\logs\maid.log をメモ帳で開いてください。起動すらしないときは、このフォルダの maid-crash.log を見てください。
詳しい説明は、maid のリポジトリ（https://github.com/yuiveslkao/maid）の docs/SETUP_WINDOWS.md にあります。
